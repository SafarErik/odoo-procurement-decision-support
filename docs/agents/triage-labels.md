# Triage labels

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer must evaluate the issue |
| needs-info | needs-info | More information is required |
| ready-for-agent | ready-for-agent | Fully specified work suitable for an agent |
| ready-for-human | ready-for-human | Human action or implementation is required |
| wontfix | wontfix | Will not be actioned |

Use these exact strings. Reuse existing labels and create only missing labels.
A ready label describes readiness; it does not grant publication, Odoo writes,
Drive edits or other authority beyond the user's request.
